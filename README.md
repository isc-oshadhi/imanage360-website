# iManage360 Website

This is the official marketing and landing page website for **iManage360**, a next-generation all-in-one ERP solution developed by **iTeq Solution Center**.

## 🚀 Overview

The iManage360 platform is designed to simplify complex business operations for industries like Logistics, Healthcare, Manufacturing, and Professional Services. This frontend application serves as the main entry point for potential clients to explore modules, view pricing, and request demos.

### Pages Included
* **Home (`/`)**: Main landing page with animated mockups and product highlights.
* **Features (`/features`)**: Deep dive into core capabilities with data visualization mockups.
* **Modules (`/modules`)**: A comprehensive grid of the 12+ ERP modules offered.
* **Industries (`/industries`)**: Tailored solutions for specific business sectors with testimonials.
* **Pricing (`/pricing`)**: Interactive pricing tiers with monthly/annual toggle and FAQs.
* **About Us (`/about`)**: The story, mission, and leadership team of iTeq Solution Center.
* **Contact (`/contact`)**: Contact form, location information, and demo scheduling.

## 🛠️ Technology Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Language:** TypeScript / React
* **Styling:** Inline CSS and custom layout architecture (designed for maximum compatibility and zero-conflict rendering)
* **Icons:** [Lucide React](https://lucide.dev/)

## 💻 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application running.
